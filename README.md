# dsh-upload-gate · 上载闸（插件）

护栏前置令：**任何出口会产生不可回滚后果的强能力，出口前先铸护栏**（限额／指纹／回滚位）。
本插件只做出厂预检与凭据面盘点——**不代传、不读密钥值、不发网络请求**。

## 区块 `ql:upload`（默认排序 140）

护栏三型（限额/指纹/回滚位）· 出厂三检（存在/机密/体量）· 上载即留痕 · 机密零外发 · 无护栏强能力禁出厂。

## 工具 `ql_upload`

| action | 干什么 |
|---|---|
| `预检` | 对目标文件跑三检：存在与体量、文件名禁传标记、内容密钥/证件号指纹 → PASS/BLOCK |
| `凭据面` | 只报"有没有"云凭据（环境变量名与候选文件存在性），**不打印任何值** |

## 诚实边界

- 预检≠上载：真正的 COS 上传仍要主人给凭据、走护栏（限额+回滚位），本插件一步都不代跑。
- 内容指纹是**模式匹配**：能抓典型密钥格式，抓不到被改写/分片的密钥。
- 体量阈值 50MB 是提示，不是硬拒——大文件该分包，判据在主人。
